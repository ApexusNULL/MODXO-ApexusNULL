# MODXO ApexusNULL

An RP2040-based reconstruction of the Modxo Lite V1 for the original Xbox, intended to run Modxo firmware using the YD-RP2040 pin mapping.

The board supplies a custom BIOS through the Xbox LPC connection and provides USB-C programming, indicator LEDs and accessory connections.

## Files

- **MODXO_ApexusNULL_Community_KiCad:** Editable KiCad PCB, schematics, footprints, symbols and models.
- **MODXO_ApexusNULL_Community_Project:** Gerbers, sourced BOM, placement data, assembly drawings and build notes.

The complete assembly includes 51 components: 50 on top and the LPC socket underneath.

## Prototype status

This reconstructed revision has not yet been physically assembled and boot-tested. Review the included build notes and sourcing exceptions before ordering.
